# CineBox Media

Assets GIF originais utilizados remotamente pelo CineBox para reduzir o tamanho do ZIP do add-on.

- Publicado com GitHub Pages.
- URLs diretas: `https://trainagain2.github.io/cinebox-kodi-media/assets/gifs/<nome>.gif`
- O manifesto contém tamanho e SHA-256 de todos os ficheiros publicados.

Não remover nem renomear assets existentes sem lançar uma versão compatível do CineBox.
